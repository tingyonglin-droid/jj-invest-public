# 0050 最新歷史高點以來市場水位圖設計

## 目標

把既有「最近七個交易日」市場水位圖改成「從最新歷史最高收盤價當日開始」的完整走勢。使用者可沿著這一輪回撤週期查看每個交易日的 0050 價格與市場水位；未來 0050 出現新的歷史最高收盤價時，圖表會自動從新高當日重新起算。

## 資料定義

- 歷史最高價只使用 Yahoo Finance 回傳的有效交易日收盤價計算，不使用盤中即時價重設高點。
- 在截至目前日期的所有有效收盤價中找出最高價格；若相同最高價出現多次，採用日期最新的一筆作為本輪起點。
- 圖表保留起點當日到目前為止的每一筆有效交易日資料，不限制七筆，不補入週末、休市日或缺值日期。
- 起點當日的市場水位為 `0%`。其他點都以這個歷史最高收盤價計算：`收盤價 / 歷史最高收盤價 - 1`。
- 有效即時價可覆蓋同日收盤點，或在尚無同日收盤時追加成最新點；即時價只影響目前價格與目前市場水位，不改變歷史最高收盤價及起點。
- 若後續歷史資料出現更高的收盤價，或在較晚日期再次收在相同歷史最高價，模型會把起點移到該最新高點日期，舊一輪走勢不再顯示。

## 資料流程與模型

`createBenchmarkDrawdown` 繼續接收完整歷史價格及可選的即時報價。處理順序為：

1. 過濾無日期、非正數價格、週末資料。
2. 依日期去重，同日保留最後一筆有效價格，並依日期升冪排序。
3. 僅以歷史收盤序列尋找最高收盤價與其最新日期。
4. 合併即時價作為目前點。
5. 從最高收盤價日期開始擷取所有交易日，建立 `history`。

既有回傳欄位維持不變，`history` 從最多七筆改為可變長度。每筆仍包含：

```js
{
  date: "2026-06-22",
  price: 111.15,
  drawdownRatio: 0,
  level: "normal"
}
```

## 圖表與互動

- 沿用原生 SVG、0% 至 -30% 的固定垂直尺度，以及正常／觀察／風險三個背景區間。
- 圖表寬度依交易日數量增加，保留足以點擊與閱讀的最小點距；少量資料時仍至少填滿卡片寬度。
- 桌面寬度足夠時直接顯示；超出卡片或手機寬度時，圖表區域提供水平捲動，不壓縮或省略交易日點位。
- 每個交易日都畫折線節點與市場水位百分比。日期標籤依可讀性抽樣，但第一天、最後一天必定顯示；資料點本身不抽樣。
- 每個點可用滑鼠、觸控或鍵盤開啟小方框，顯示日期、0050 價格、相對歷史高點的百分比與市場區間。
- 切換點位時只顯示一個小方框；點擊同一點或圖表空白處關閉。
- 無障礙標籤改為「0050 自最新歷史最高收盤價以來的市場水位走勢圖」，不再宣稱只有七個交易日。

## 響應式與捲動行為

- 圖表座標模型提供動態 `width`、`viewBox` 與點位座標；背景區間、門檻線及右側價格標籤延伸到完整圖表寬度。
- 外層圖表容器使用水平捲動，垂直方向不捲動；卡片本身不超出頁面。
- 初次載入時捲到最右側，讓使用者先看到最新市場水位；仍可向左查看 6/22 或未來的新高起點。
- 點位小方框限制在完整 SVG 邊界內，左右邊緣點位不會溢出。

## 空資料與錯誤處理

- 沒有有效歷史收盤資料時不渲染市場水位卡。
- 只有一筆有效資料時顯示單一 0% 點，置於圖表中央。
- 即時報價失敗時，以最新有效收盤價作為目前值。
- 歷史 API 失敗時沿用現況，不以不完整資料臆造高點。

## 測試與驗收

- 模型測試先驗證失敗再實作：從最新最高收盤價開始、保留所有後續交易日、相同高點採較晚日期、新高後自動重設、即時價不重設高點。
- 圖表模型測試：點數增加時寬度成長、最小點距、第一與最後日期標籤、門檻線延伸、邊緣小方框位置。
- UI 測試：更新後的說明文字、水平捲動容器、動態 SVG 寬度及每點互動標籤。
- 執行完整測試、程式碼檢查與正式建置。
- Vercel Preview 人工檢查桌面與手機：從 2026/06/22 開始、每個交易日都有點、可水平滑動、最新點預設可見、小方框資料正確。

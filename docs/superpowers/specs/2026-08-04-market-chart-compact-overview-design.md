# 市場水位卡片緊湊總覽設計

## 目標

改善市場水位卡片在手機上的資訊密度，讓模式切換更容易找到，並讓「全部曲線」專注呈現從最新歷史最高收盤價到目前的整體走勢。

## 版面

- 將模式切換按鈕移到「市場水位」標題列右側。
- 標題、摘要與圖表仍維持原本資訊順序。
- 縮小卡片頂端內距、標題區下方間距、摘要區下方間距，以及圖表前的垂直留白。
- 手機版標題與按鈕必須同列；按鈕文字可維持「看全部曲線」與「查看詳細點位」，且保留至少 44px 的操作高度。
- 摘要數值不得因壓縮留白而重疊或截斷。

## 模式行為

### 詳細模式

- 預設仍為詳細模式。
- 保留水平滑動並自動定位最新點。
- 保留每個點位的下跌百分比文字。
- 保留目前的日期密度與逐點點擊、觸控、鍵盤操作。

### 全部曲線模式

- 完整保留從最新歷史最高收盤價到目前的所有交易日點位與曲線。
- 不在圖上永久顯示任何點位的下跌百分比文字。
- 日期只顯示起始日、目前日期，以及中間約 2–3 個等距抽樣日期。
- 抽樣日期必須依資料長度自動計算，不得寫死特定日期。
- 點擊或觸控圖表仍選取最近點位，提示框繼續顯示日期、0050 股價、下跌百分比與市場區間。
- 切回詳細模式時恢復完整的百分比與日期顯示規則。

## 資料與狀態

- 不變更歷史資料抓取、最新高點判定、即時價格或市場區間計算。
- 圖表模型繼續負責模式相關的永久標籤密度；React 只負責模式狀態、按鈕與點位互動。
- 模式切換不重新抓資料，也不改變最高價、目前價或跌幅。

## 驗證

- 模型測試確認全部曲線模式的百分比標籤數為零。
- 模型測試確認日期包含首尾，且長序列總日期標籤約為 4–5 個。
- UI 合約測試確認按鈕位於標題區，而非圖表上方的獨立工具列。
- 保留詳細模式、捲動、最近點選取、點位提示框及區間名稱測試。
- 執行完整測試、Lint 與 Next.js 建置。
- 僅更新 `codex/market-level-7d-chart` 與 Vercel Preview，不合併 `main`、不建立 Production deployment。

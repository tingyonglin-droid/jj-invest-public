# Betree 品牌頁首與 App icon 設計

## 目標

將公開版 App 首頁頂部品牌名稱改為置中的手寫風格 `Betree`，借鑑 Instagram 首頁字標的輕巧品牌感，同時減少頁首占用的垂直空間。同步將安裝名稱更新為 `Betree 曝險管理`，並建立源自 Threads 黑白視覺語言的新 App icon。

## 範圍

- 修改一般使用者 App 的首頁頁首、安裝名稱與 App icon。
- 移除頁首現有的三段柱狀品牌圖形與 `JJ Invest System` 文字。
- 頁首只顯示單行 `Betree`，不顯示「曝險管理」或其他副標。
- PWA manifest、頁面 metadata 與 Apple Web App title 統一顯示 `Betree 曝險管理`。
- 本次不修改管理後台頁首、底部導覽或任何投資功能。

## 視覺設計

- `Betree` 水平置中於可用頁首寬度，而非僅相對內容起點置中。
- 採用與已確認視覺方向一致的 Caveat 手寫字體，字重為 Medium；應以專案內可穩定載入的方式提供，並設定 cursive 後備字體。
- 字標維持深炭色，沿用既有莫蘭迪中性色彩系統，不加入 IG 彩虹漸層或額外裝飾。
- 頁首維持單列，字標不得因字體載入或窄螢幕而換行。
- 保留足夠的上下留白，使字標清楚但不比現有頁首更高。

## App icon

- 使用純黑底與單一白色抽象符號，不加入文字、灰階、漸層、陰影或裝飾框線。
- 主圖形為藝術化、抽象的大寫 `B`，呼應 `Betree` 品牌名稱，但不直接使用一般字型字形。
- `B` 使用連續左側主幹、較小的上方量體與較大的下方量體，表達資產由小累積到大的成長。
- 中間以黑色負空間分隔上下量體，輪廓保持圓潤、穩定且適合小尺寸辨識。
- 圖形採藝術化、抽象表現，不直接畫樹、葉子、錢幣、箭頭、長條圖或傳統金融符號。
- 圖形不得複製 Threads glyph 或其他既有商標，只延續黑底白色簡圖、粗線條與小尺寸辨識度的視覺原則。
- 產出並替換 192px、512px、maskable 512px 與 Apple touch icon；各尺寸需保留足夠安全區域，避免系統裁切。

## 響應式與可用性

- 320px 以上手機寬度與桌面容器皆保持視覺置中。
- 字體載入前後不得造成明顯版面位移；字標需有合理的後備字體與尺寸。
- `Betree` 是品牌識別文字，不新增點擊行為，也不偽裝成按鈕。
- 字標文字保留在 DOM 中，不以圖片取代，以維持縮放清晰度與可存取性。
- App icon 在約 48–60px 的手機桌面尺寸仍需保持輪廓清楚，不依賴細線或微小負空間。

## 驗證

- 更新或新增 UI 測試，確認首頁頁首包含 `Betree`，且不再包含 `JJ Invest System` 與頁首柱狀圖形。
- 更新 PWA 測試，確認 manifest、metadata、Apple Web App title 與全部 icon 路徑及尺寸正確。
- 以實際縮圖檢查 48px、60px、192px 與 512px icon 的辨識度、安全區域與黑白對比。
- 執行相關測試、完整測試、lint 與正式建置。
- 於 320px、375px 與桌面寬度檢查字標置中、單列與頁首高度。

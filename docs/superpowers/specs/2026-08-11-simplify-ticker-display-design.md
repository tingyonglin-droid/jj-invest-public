# 簡化標的代號顯示設計

## 目標

簡化使用者看到的標的資訊：再平衡清單不再顯示代號左側的圓形圖示，台股代號不顯示交易所後綴，設定畫面不再顯示「正規化代號」提示。內部資料、報價查詢與再平衡計算仍使用完整正規化代號。

## 顯示規則

- `00631L.TW` 顯示為 `00631L`。
- `00864B.TWO` 顯示為 `00864B`。
- 非台股代號（例如 `QLD`、`SGOV`）維持原樣。
- 格式轉換集中在共用顯示函式，避免各畫面重複處理字串。

## 畫面調整

### 再平衡清單

- 正二、原形與類現金三類清單共用相同修改。
- 移除每列代號左側的圓形代號圖示。
- 調整列內版面，讓代號與名稱區塊自然向左補位。
- 可見代號及勾選框的無障礙標籤皆使用不含台股後綴的顯示代號。

### 設定畫面

- 移除持股設定中的整行「正規化代號：…」。
- 移除類現金設定中的整行「正規化代號：…」。

### 操作清單文字

- 若產生可複製的操作清單文字，台股代號使用不含 `.TW` 或 `.TWO` 的顯示格式。

## 不變範圍

- 不修改使用者輸入的原始代號。
- 不修改正規化代號的儲存格式。
- 不修改報價 API、報價來源、幣別判斷或再平衡計算。
- 不修改美股代號的顯示。

## 測試與驗證

- 為共用顯示函式新增測試，涵蓋 `.TW`、`.TWO`、美股代號與空值。
- 為再平衡清單新增或更新 UI 結構測試，確認圓形圖示已移除、可見代號使用簡潔格式。
- 更新設定畫面測試，確認兩處「正規化代號」提示皆不存在。
- 更新操作清單文字測試，確認台股後綴不會出現在輸出中。
- 執行相關測試、完整測試、程式碼檢查與正式建置。

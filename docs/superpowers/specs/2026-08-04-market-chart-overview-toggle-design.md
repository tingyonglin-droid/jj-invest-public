# 0050 市場水位圖全覽切換設計

## 目標

在既有「從最新歷史最高收盤價開始」的市場水位圖上增加 SVG 雙模式切換。詳細模式維持可水平滑動與逐點查看；全覽模式把最高點到目前的完整曲線放進卡片寬度，讓使用者一次掌握整輪下跌走勢。

## 名稱調整

所有市場水位區間的使用者介面文字統一為：

1. 正常區間：0% 至 -10%。
2. 觀察區間：-10% 至 -20%。
3. 股災區間：-20% 以下。

內部資料層級值 `normal`、`prepare`、`deep` 維持不變，避免影響既有顏色分類與計算；只更改對外文字。原有「風險區間」不得再出現在市場水位卡、圖例、點位小方框或無障礙標籤中。

## 雙模式互動

市場水位圖預設使用詳細模式：

- 每個交易日保留至少 44px 點距。
- 圖表超出卡片時可水平滑動。
- 資料載入或切回詳細模式時，自動定位到最新點。
- 模式按鈕文字為「看全部曲線」。

點擊「看全部曲線」後切換為全覽模式：

- 所有交易日點位平均配置在卡片可用寬度中，不出現水平滑動。
- 最高點與最新點必定可見，完整折線從左至右一次呈現。
- 模式按鈕文字改為「查看詳細點位」。
- 再次點擊回到詳細模式。

模式切換只改變圖表水平座標與標籤密度，不改變價格、回撤、市場區間、歷史高點或資料範圍。

## 圖表模型

`createBenchmarkDrawdownChart(history, highPrice, options)` 新增可選的 `mode`：

```js
createBenchmarkDrawdownChart(history, highPrice, { mode: "detail" });
createBenchmarkDrawdownChart(history, highPrice, { mode: "overview" });
```

- `detail` 沿用動態寬度與最小點距。
- `overview` 固定使用基準寬度 760，將全部點位平均分布在繪圖區。
- 回傳模型新增 `mode`，讓 UI 與捲動效果使用同一個明確狀態。
- 全覽模式降低永久顯示的百分比與日期標籤密度；第一點、最後一點必定顯示。
- 不論模式，每個圓點都保留點擊、觸控、鍵盤操作與完整 `aria-label`。

## UI 與響應式行為

- 模式按鈕位於圖表上方，使用一般按鈕元素並提供足夠觸控尺寸。
- 按鈕使用 `aria-pressed` 表示是否處於全覽模式。
- 詳細模式的外層容器維持 `overflow-x: auto`。
- 全覽模式加入專屬 class，將 SVG 寬度限制為容器的 100%，並隱藏水平溢出。
- 桌面與手機共用相同切換邏輯；全覽模式在手機上仍完整顯示整條曲線。
- 點位小方框沿用現有定位與內容；模式切換時關閉已開啟的小方框，避免舊座標殘留。

## 錯誤與邊界

- 單一資料點在兩種模式都置中顯示。
- 資料尚未載入時不顯示市場水位卡或模式按鈕。
- 切換模式不重新取得 API 資料，也不修改目前市場水位。
- 全覽模式點位較密時仍保留全部可操作點，但只抽樣永久文字標籤。

## 測試與驗收

- 圖表模型測試：詳細模式寬度隨點數成長；全覽模式固定 760 並保留所有點；兩種模式的 Y 座標、價格與回撤一致。
- 標籤測試：全覽模式第一點與最後一點一定顯示，長序列抽樣數量低於詳細模式。
- UI 測試：模式按鈕文案、`aria-pressed`、詳細／全覽 class 與「股災區間」文字正確。
- 互動驗收：預設詳細模式、切換全覽、再切回詳細；小方框在兩種模式都可操作，切換時會關閉。
- 執行完整測試、ESLint 與 Next.js production build。
- 建立來源為最新功能分支提交的 Vercel Preview，確認 `main` 與 Production 不變。

# 緊湊設定與莫蘭迪配色設計

## 目標

降低手機設定頁的垂直長度，讓持股與再平衡參數更容易掃讀及編輯；同時建立一致的低飽和莫蘭迪色彩系統，在設定、再平衡與總覽畫面清楚區分正二、原形及現金＋類現金。

## 持股設定

### 自動分配

- 每檔標的保留標題與「移除」操作於同一列。
- 代號與股數輸入框左右並排，各占可用寬度的一半。
- 保留適合觸控的最小高度，但縮減卡片內距、欄位間距與區塊間距。
- 新增按鈕降低垂直內距。

### 自訂個股佔比

- 第一列仍為代號與股數左右並排。
- 第二列使用完整寬度的「同類資產內目標比例」輸入框，右側顯示固定 `%` 後綴。
- 正二與原形各自在標的清單下方顯示配置合計。
- 合計正確時顯示 `100%`；錯誤時保留既有驗證規則及清楚的錯誤提示。

### 現金與類現金

- 類現金標的沿用相同的緊湊卡片結構：代號與股數並排，自訂模式的比例置於第二列。
- 現金與類現金仍屬同一資產桶，不更動計算、資料結構或驗證規則。

## 再平衡參數

- 「再平衡到 Beta」改為單一橫列：左側標題，右側依序為減號、數值輸入框、加號。
- 數值輸入框不再占滿整列，寬度只需容納 Beta 數值。
- 「台股交易精度」改為下一個橫列：左側標題，右側為「精確到張數／精確到股數」分段選擇。
- 「美股固定精確到股數。」保留在交易精度列下方。
- 所有控制維持至少 44px 的手機觸控目標。

## 資產分類色彩

全 App 使用同一組低飽和分類色：

- 正二：灰紫 `#9B8AA1`，極淡背景 `#F5F2F5`。
- 原形：鼠尾草 `#87988A`，極淡背景 `#F2F4F1`。
- 現金＋類現金：霧灰藍 `#8797A4`，極淡背景 `#F2F4F5`。

套用位置：

- 持股設定的正二與原形外層區塊。
- 現金設定的現金與類現金外層區塊。
- 再平衡頁的正二、原形與類現金清單外層區塊。
- 總覽頁資產配置的圓點、比例條與對應標示。

分類色只用於外框、短標題色條、極淡背景及小型識別元素。個別標的卡與輸入框維持暖白底及中性框線，避免巢狀彩色外框。

## 操作與狀態色彩

- 選取中的分段控制：暖灰褐背景 `#DDD7CF`、框線 `#BBB2A8`、文字 `#5E5852`。
- 新增按鈕：象牙灰米 `#ECE8E2`、文字 `#585A58`。
- 移除文字：乾燥玫瑰 `#A07779`。
- 正確的配置合計：灰鼠尾草 `#78867D`。
- 錯誤提示與危險確認仍保留足夠辨識度，不以柔和配色犧牲錯誤語意。

## 總覽頁配色

- App 背景使用暖灰白，卡片使用暖白，框線與陰影改為中性暖灰。
- Beta 的「需再平衡」狀態使用柔和沙金色；Beta 軌道使用暖灰、灰鼠尾草目標標記與深炭色目前標記。
- 市場水位正常／觀察／風險區間分別使用淡鼠尾草、柔和沙色與乾燥玫瑰；圖表線維持深灰以確保可讀性。
- 時間範圍及底部目前頁籤的選取狀態使用暖灰褐，不使用鮮綠。
- 資產配置使用灰紫、鼠尾草及霧灰藍三種分類色。

## 行為與無障礙

- 不修改任何資產計算、報價、儲存、再平衡或驗證行為。
- 不使用顏色作為唯一識別方式；既有標題、文字與狀態標籤均保留。
- 文字與背景維持足夠對比，鍵盤焦點樣式不可移除。
- 手機與桌面版皆不可出現欄位溢出或控制重疊。

# 0050 七日市場水位圖設計

## 目標

把首頁現有的「市場水位」摘要卡升級為可視化折線圖，讓使用者一眼看出 0050 最近七個交易日相對歷史最高收盤價的回撤走勢，同時保留目前高點、目前價格與市場區間的判讀。

## 範圍

- 顯示最近七筆有效交易日收盤資料；週末、休市日和無效價格不計入七日。
- 若當日即時報價有效，以即時報價取代同日收盤點，或在尚無同日收盤時新增為最新點；圖表仍最多七點。
- 所有點皆以完整歷史資料中的最高收盤價為共同基準計算回撤。
- 保留現有資訊說明按鈕與說明內容。
- 不新增資料庫、第三方圖表套件或新的外部資料服務。

## 資料模型與流程

現有首頁繼續平行取得 0050 歷史價格與即時報價，並交由 `createBenchmarkDrawdown` 建立單一市場水位模型。模型在既有的高點、目前價格、目前回撤與區間之外，新增 `history`：

```js
{
  date: "2026-08-03",
  price: 102.03,
  drawdownRatio: -0.0821,
  level: "normal"
}
```

輸入先移除無日期、非正數價格，依日期排序，同日資料保留最後一筆。歷史最高點從全部有效收盤價計算；最近七日則從去重後序列尾端擷取。有效即時價會先合併進序列，再進行七筆截取；但即時價高於既有歷史高點時，不把盤中價格改寫成「歷史最高收盤價」，以維持既有指標定義。此時當前回撤可短暫為正值。

## 介面設計

### 卡片頂部

- 左側：標題「市場水位」、資訊按鈕、副標「0050 距歷史高點」。
- 右側：分成「歷史高點（收盤）」與「目前（即時／收盤）」兩組摘要，顯示價格、日期與目前回撤。
- 即時報價有效時標示「目前（即時）」；否則標示「目前（收盤）」。

### 圖表

- 使用原生 SVG 繪製折線、圓點、百分比與日期，不引入圖表依賴。
- 垂直尺度固定涵蓋 0% 至 -30%，使不同日期的圖表具有一致視覺意義；高於 0% 的點貼齊頂部並保留正值標示，低於 -30% 的點貼齊底部。
- 背景分成三個水平區域：
  - 正常區間：0% 至 -10%，綠色。
  - 觀察區間：-10% 至 -20%，橘色。
  - 風險區間：-20% 以下，紅色。
- 0%、-10%、-20% 以虛線區隔；右側同時顯示各門檻所對應的 0050 價格。
- 每一點依其區間著色，並顯示回撤百分比；日期顯示為 `MM/DD`，星期使用繁體中文單字。
- 每個資料點都是可點擊按鈕。點擊後在點位附近顯示小方框，內容包含日期、0050 股價、距歷史高點下跌百分比與市場區間名稱。
- 同時間只顯示一個小方框；點擊另一點會切換內容，點擊已選取的點或圖表空白處會關閉。鍵盤使用者可用 Tab 聚焦點位，並以 Enter 或 Space 開啟／關閉。
- 小方框會依點位所在位置向左或向右展開，並保持在圖表邊界內；不因遮住點位而改變圖表尺度。
- 圖例和資料來源／更新日期置於圖表下方。

### 響應式行為

- 桌面版完整顯示七個資料點、每點百分比、日期、星期與三區文字。
- 手機版仍顯示全部七點，但縮小字級與間距；區間說明改為精簡標籤，頂部摘要改為兩欄並允許換行。
- 手機版以點擊開啟同一份小方框，不依賴滑鼠 hover；小方框寬度限制在圖表內，文字可換行。
- 圖表不提供橫向捲動，避免首頁卡片寬度失控。

## 空資料與錯誤處理

- 沒有任何有效歷史價格時，沿用現況：不渲染市場水位卡。
- 有效歷史資料少於七筆時，顯示所有可用點，不補造資料。
- 即時報價失敗時，以最新有效收盤價作為目前值，圖表仍可使用。
- 圖表的 SVG 提供可讀的 `aria-label`，摘要資訊保留為一般文字，確保不依賴顏色才能理解。

## 測試與驗收

- 單元測試：排序、去重、過濾無效值、最近七個交易日、即時價覆蓋／追加、統一高點基準、區間分類。
- 圖表模型測試：0%、-10%、-20%、-30% 的座標與門檻價格，超出範圍的裁切，以及小方框左右展開位置。
- UI 結構與互動測試：市場水位摘要、三個區間、七日圖表及無障礙標籤存在；點擊／鍵盤操作可開啟、切換與關閉小方框，內容顯示正確股價、回撤與市場區間。
- 全專案執行測試、程式碼檢查與正式建置。
- 在 Vercel Preview 以桌面與手機尺寸人工檢查：七點不重疊、文字可讀、沒有水平溢出、資料與 API 回應一致，且左右邊緣點位的小方框不超出圖表。

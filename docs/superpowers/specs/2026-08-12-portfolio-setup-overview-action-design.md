# 首次投資組合設定動作設計

## 目標

使用者尚未完成持股與現金設定時，總覽 Beta 卡不顯示「需再平衡」，改顯示「設定持股與現金 →」並連到持股設定。完成基本資料且首次報價已取得後，才顯示正常的再平衡或平衡狀態。

## 完成條件

- 首次報價 API 已成功回應。
- 至少一筆一般持股股數大於 0。
- 台幣現金、美元現金或至少一筆類現金 ETF 股數大於 0。

## 動作優先順序

1. 尚未符合完成條件：顯示「設定持股與現金 →」，導向設定頁的持股分頁。
2. 已完成但設定驗證失敗：沿用「設定需修正 →」及既有錯誤導向。
3. 已完成且需要再平衡：顯示「需再平衡 →」。
4. 已完成且在容許範圍內：顯示「不需再平衡」。

## 邊界

- 不修改投資組合、Beta 或再平衡公式。
- 不新增導覽頁或儲存欄位。
- 背景報價尚未首次成功回應時，一律視為尚未完成，不讓暫態零值產生再平衡建議。
- 設定頁內既有欄位驗證與錯誤摘要維持不變。

## 驗證

- 單元測試涵蓋未報價、無持股、無現金、台幣現金、美元現金、類現金與完成後的三種正常動作。
- UI 測試確認 Beta 卡仍使用既有按鈕連結與設定頁導向。
- 執行完整測試、lint 與 production build。

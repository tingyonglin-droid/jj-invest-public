# 歷史摘要更新日期文字設計規格

日期：2026-08-17

## 目標

降低歷史摘要卡片中更新日期的視覺權重，讓四項主要數據維持畫面焦點。

## 已確認設計

1. 移除標題區目前的綠色日期膠囊。
2. 更新日期移到四個歷史摘要數據格的下方。
3. 顯示文字格式固定為 `更新日期：YYYY-MM-DD`，例如 `更新日期：2026-08-17`。
4. 日期文字靠左對齊。
5. 日期文字與摘要數據格保持 10px 上方間距。
6. 不使用底色、邊框、圓角或膠囊內距。
7. 使用現有次要文字色彩與小字級，桌面與手機維持相同資訊順序。

## 範圍

- 僅調整歷史頁最上方摘要卡片的更新日期。
- 不改動圖表日期範圍、最近紀錄日期、歷史資料內容或計算方式。

## 驗收條件

1. 標題區不再出現綠色日期膠囊。
2. 四個摘要數據格下方顯示 `更新日期：` 加最新歷史日期。
3. 日期為無背景的小型灰色文字，與數據格相距 10px。
4. 桌面與手機均無重疊、裁切或額外空白區塊。
5. 現有歷史圖表與其他頁面不受影響。

## 測試

1. UI 原始碼測試確認日期文字位於摘要格之後。
2. CSS 測試確認小字色彩、字級、10px 間距，且不再存在膠囊背景樣式。
3. 執行完整測試、正式建置及手機／桌面視覺檢查。
